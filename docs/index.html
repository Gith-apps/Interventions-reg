Mes Interventions Pro

Ivass EM · relevé automatique · preuves · contrôle de paie

Ajouter des captures d'écran

Prends une capture de chaque intervention (l'en-tête jaune/bleu + l'écran « Détails » défilé jusqu'à la Référence PTO), ou de la liste du jour. Sélectionne-les toutes d'un coup : le logiciel lit le n° EPS, la date, le client, l'adresse, la PTO, le type et le mode de raccordement, puis garde la capture comme preuve.

Comparer avec le fichier Excel de l'entreprise

Importe le relevé envoyé par ta boîte (.xlsx, .xls ou .csv). Le logiciel retrouve la colonne des n° EPS, compare avec tes interventions du mois choisi en haut, et détecte : interventions non payées, type différent, montant différent, doublons et lignes inconnues.

Résultat détaillé

Grille de prix par type d'intervention

Saisis ce que tu dois toucher pour chaque type. Le prix est appliqué automatiquement à chaque intervention (tu peux aussi forcer un prix sur une intervention précise). Les interventions annulées comptent 0 €. Les interventions clôturées KO utilisent le tarif « Clôture KO » (mets 0 si elles ne sont pas payées, ou le prix du déplacement).

Clôture du mois

Crée le fichier Excel complet du mois choisi (liste détaillée + récapitulatif par type + dernier rapport de comparaison), et une sauvegarde avec les captures-preuves.

Envoyer du téléphone vers le PC

Sur le téléphone : « Envoyer » ouvre le partage Android/iPhone (WhatsApp, Gmail, Drive…). Sur le PC : « Importer » le fichier reçu — les interventions sont fusionnées par n° EPS, sans doublon.

Sauvegarde complète

Tout est stocké dans cet appareil (navigateur). Fais une sauvegarde régulière : elle contient toutes les interventions, les tarifs et les preuves.
