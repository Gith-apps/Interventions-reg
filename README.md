## Ce que fait l'application
- **Enregistrement automatique** de tes interventions quand tu les consultes dans tes applications de travail : n° EPS, date, horaires, type (raccordement, PLP, SAV), clôture OK / KO, priorité, commune.
- **Lecture seule** : elle ne clique sur rien, ne modifie rien et n'envoie rien.
- **Ajout de captures** quand la détection automatique n'a pas fonctionné (les images sont lues puis supprimées).
- **Suivi du mois** : recherche, filtres, statistiques par type et par clôture.
- **Export** de ton relevé vers ton ordinateur ou ton stockage.
- **Mises à jour** proposées directement dans l'application.

## Confidentialité et transparence
- Aucun **téléphone**, aucune **adresse**, aucun **nom de contact** client n'est enregistré.
- Tes données restent **sur ton téléphone**. Rien n'est envoyé à l'éditeur ni à un serveur.
- L'éditeur ne voit **que les informations de ta licence** (nom ou pseudo, contact, code appareil, formule, dates, paiements).
- Il n'a **aucun accès** à ton écran, à tes comptes, à tes identifiants ni à ton utilisation de l'application.

## Installation (Android 5 ou plus)
1. Télécharge le fichier **IvassEM-Interventions.apk** depuis la [dernière version](https://github.com/Gith-apps/interventions-reg/releases/latest).
2. Ouvre-le et autorise **« Installer des applications inconnues »** si Android le demande. Si Play Protect affiche un avertissement : **Plus de détails → Installer quand même**.
3. Ouvre l'application, lis et accepte les conditions.
4. Touche **Activer la détection** → **Accessibilité** → **Ivass EM Interventions** → **Activer**.
   Bouton grisé (« paramètre restreint ») : Paramètres → Applications → Ivass EM Interventions → **⋮** → **Autoriser les paramètres restreints**, puis recommence.
5. Dans **🎯 Que faut-il lire ?**, coche les applications de ton entreprise.
